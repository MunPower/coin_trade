# 코인002 — 코인001 + 업비트 자동매매

코인001(거래대금 TOP10 리스트 + 추세전환 차트)에 **자동매매 칸**을 더한 버전입니다.
리스트 아래에 예수금과 코인별 **매수가 · 매도가 · 수량(또는 금액)** 입력 표가 나옵니다.

## 화면
업비트 리스트에서 **코인 줄을 누르면 바로 그 아래에 칸이 펼쳐집니다.** (다시 누르면 접힘, 한 번에 하나)
펼친 칸: 코인·현재가 / 곡선 방향 / 상한·곡선·하한 값 / 보유·진행 / 매수 금액 / [곡선상한] [곡선] [곡선하한] 버튼, 오른쪽 위 📈 차트 보기.
실행 중인 버튼은 리스트 줄의 코인 이름 옆에 작은 '상·곡·하' 표시로도 보입니다.
리스트 아래에는 예수금 · 모드(모의/실전) · 자동매매 켜기 · 진행 현황이 있습니다.

## 동작 방식 — 차트의 세 선 기준
코인마다 **[매수 금액] [곡선상한] [곡선] [곡선하한]** 이 있고, 버튼을 누를 때마다 글씨가 **실행 ↔ 취소**로 바뀝니다.
(글씨가 '취소'로 보이면 지금 켜져 있다는 뜻 — 한 번 더 누르면 꺼집니다)

| 곡선 방향 | 곡선하한(매수선) | 곡선(중간선) | 곡선상한(매도선) |
|---|---|---|---|
| ▼ 하락 중 | 매수 | **절반 매도** | 남은 것 전부 매도 |
| ▲ 상승 중 | 매수 | (팔지 않음) | 전부 매도 |

- 곡선 방향은 차트 아래 '곡선추세 방향' 막대와 같은 기준(오늘 곡선 값이 어제보다 낮으면 하락)입니다.
- 세 선은 차트와 **똑같은 계산**이고, 오늘 캔들은 지금 가격으로 바꿔서 3초마다 다시 계산합니다.
- 켜 둔 버튼만 동작합니다. 예) 곡선하한 + 곡선상한만 실행 → 하한에서 사고 상한에서 다 팖.
- 곡선하한이 '실행'이면 다 팔고 난 뒤 다음 하한에서 **다시 삽니다.** 한 번만 하려면 산 뒤에 곡선하한을 취소하세요.
- 곡선하한 없이 곡선/곡선상한만 실행하면 **이미 가진 코인**을 팝니다. (실전 모드)
- 주문은 지정가: 매수는 하한 값을 호가 단위로 내림, 매도는 곡선/상한 값을 올림. 최소 주문 5,000원.
- 절반이 5,000원보다 작으면 곡선 절반 매도는 건너뛰고 상한까지 들고 갑니다.
- 걸려 있는 주문은 그 버튼을 '취소'하면 업비트 주문도 같이 취소됩니다.
- 예수금이 모자라면 주문하지 않고 기다립니다. 기록은 화면 "매매 기록"과 `trade_log.csv`에 남습니다.

## 꼭 지켜 주세요
1. **처음에는 모의 모드로** 충분히 확인하세요. (실제 주문 없이 체결됐다고 치고 기록만 남김)
2. 업비트는 **주문 권한 키에 허용 IP 등록이 필수**입니다. Streamlit Cloud는 IP가 계속 바뀌어서
   실전 주문이 안 됩니다 → **내 PC에서 실행**하세요. (아래 방법)
3. API 키를 만들 때 **출금 권한은 절대 체크하지 마세요.** (자산조회·주문조회·주문하기만)
4. `secrets.toml`은 GitHub에 올리면 안 됩니다. (`.gitignore`에 빠져 있음)
5. 프로그램을 다시 켜면 안전을 위해 **자동매매는 꺼진 상태**로 시작합니다.

## 1) API 키 만들기 (업비트)
1. PC에서 업비트 로그인 → 고객센터 → Open API 안내 → Open API 사용하기
2. 권한: **자산조회, 주문조회, 주문하기** 체크 (출금 ❌)
3. 허용 IP: 내 PC의 공인 IP 입력 (네이버에서 "내 아이피" 검색)
4. 발급된 Access Key / Secret Key 복사 (Secret Key는 한 번만 보여요)

## 2) 내 PC에서 실행
```bash
pip install -r requirements.txt
# .streamlit/secrets.toml.example 을 복사해 secrets.toml 로 이름 바꾸고 키 입력
streamlit run app.py
```
브라우저가 열리면 업비트 화면 아래 **🤖 자동매매**에서 설정 → [💾 설정 저장] → [자동매매 켜기].
브라우저를 닫아도 **명령창(터미널)이 켜져 있는 동안** 계속 감시합니다. PC가 꺼지거나 절전되면 멈춰요.

## 파일
- `app.py` — 화면 (코인001 + 자동매매 칸)
- `trader.py` — 자동매매 엔진 (업비트 인증·주문·감시)
- `.streamlit/secrets.toml.example` — 키 넣는 파일 예시

※ 자동매매는 손실이 날 수 있고, 프로그램 오류·인터넷 끊김·업비트 점검 등으로 주문이 늦거나 안 될 수 있습니다.
투자 판단과 책임은 본인에게 있습니다.
